# 数学手册 抽认卡

## 第 1 章：算术与初等代数

### 卡片：复利终值公式怎么写？
- **背面**：S=P(1+i)ⁿ
- **标签**：代数
- **章节**：ch01

### 卡片：等差与等比求和各一条公式
- **背面**：等差 n(a₁+aₙ)/2；等比 a₁(1−qⁿ)/(1−q)
- **标签**：代数
- **章节**：ch01

### 卡片：五次方程为什么不能根式解？
- **背面**：阿贝尔-鲁菲尼定理证明一般五次及以上方程没有根式解，但有数值解
- **标签**：代数
- **章节**：ch01

### 卡片：分式方程为什么必须验根？
- **背面**：去分母时乘以了可能为零的式子，会产生增根
- **标签**：代数
- **章节**：ch01

### 卡片：复数除法怎么算？
- **背面**：分子分母同乘分母的共轭，分母变成 c²+d²
- **标签**：代数
- **章节**：ch01

## 第 2 章：函数与初等函数

### 卡片：幂律在什么坐标下是直线？
- **背面**：双对数坐标，斜率就是指数
- **标签**：函数
- **章节**：ch02

### 卡片：arcsin 和 1/sin 有什么区别？
- **背面**：前者是反函数，后者是倒数，两者完全不同
- **标签**：函数
- **章节**：ch02

### 卡片：摆线的参数方程？
- **背面**：x=a(t−sin t)，y=a(1−cos t)
- **标签**：函数
- **章节**：ch02

### 卡片：悬链线的方程形式？
- **背面**：y=a cosh(x/a)
- **标签**：函数
- **章节**：ch02

### 卡片：算图法的原理是什么？
- **背面**：用三条刻度尺的连线读出结果，本质是射影对应
- **标签**：函数
- **章节**：ch02

## 第 3 章：几何学

### 卡片：正弦定理怎么写？
- **背面**：a/sin A = b/sin B = c/sin C = 2R
- **标签**：几何
- **章节**：ch03

### 卡片：海伦公式？
- **背面**：S=√(p(p−a)(p−b)(p−c))，p 为半周长
- **标签**：几何
- **章节**：ch03

### 卡片：混合积为零说明什么？
- **背面**：三个向量共面，平行六面体体积为零
- **标签**：几何
- **章节**：ch03

### 卡片：高斯曲率为什么决定能否摊平？
- **背面**：它是内蕴量，等距变形不能改变它，非零则无法等距映射到平面
- **标签**：几何
- **章节**：ch03

### 卡片：二次曲线怎么分类？
- **背面**：看判别式 B²−4AC：小于零椭圆，等于零抛物线，大于零双曲线
- **标签**：几何
- **章节**：ch03

## 第 4 章：线性代数

### 卡片：矩阵乘法什么时候能做？
- **背面**：左矩阵列数等于右矩阵行数，结果取外维
- **标签**：矩阵
- **章节**：ch04

### 卡片：行列式为零意味着什么？
- **背面**：矩阵不可逆，变换把空间压到低维，信息丢失
- **标签**：矩阵
- **章节**：ch04

### 卡片：方程组三种解情形怎么判断？
- **背面**：比较 rank(A) 与 rank([A|b]) 及未知数个数
- **标签**：矩阵
- **章节**：ch04

### 卡片：实对称矩阵的特征向量有什么性质？
- **背面**：特征值全实，特征向量互相正交，可正交对角化
- **标签**：矩阵
- **章节**：ch04

### 卡片：四元数适合表示什么？
- **背面**：三维旋转，优点是无万向锁、可平滑插值
- **标签**：矩阵
- **章节**：ch04

## 第 5 章：微分学

### 卡片：梯度的两个性质？
- **背面**：方向是最快增长方向，模是最大变化率
- **标签**：微分
- **章节**：ch05

### 卡片：方向导数怎么写？
- **背面**：∂f/∂l=∇f·l，l 为单位向量
- **标签**：微分
- **章节**：ch05

### 卡片：多元极值的二阶判别式？
- **背面**：Δ=AC−B²，A=f_xx，C=f_yy，B=f_xy；Δ>0 且 A>0 为极小，Δ<0 为鞍点
- **标签**：微分
- **章节**：ch05

### 卡片：隐函数求导公式？
- **背面**：dy/dx=−F_x/F_y，条件是 F_y≠0
- **标签**：微分
- **章节**：ch05

### 卡片：泰勒展开的余项有什么用？
- **背面**：给出误差上界，决定取几阶才能达到要求精度
- **标签**：微分
- **章节**：ch05

## 第 7 章：微分方程

## 第 8 章：概率论与数理统计

### 卡片：贝叶斯公式？
- **背面**：P(B|A)=P(A|B)P(B)/P(A)
- **标签**：概率
- **章节**：ch08

### 卡片：样本方差为什么除以 n−1？
- **背面**：除以 n 会系统性低估总体方差，n−1 才是无偏估计
- **标签**：概率
- **章节**：ch08

### 卡片：95% 置信区间的正确解释？
- **背面**：反复抽样构造的区间中约 95% 包含真值，不是单个区间有 95% 概率包含真值
- **标签**：概率
- **章节**：ch08

### 卡片：中心极限定理说什么？
- **背面**：大量独立同分布随机变量之和近似正态，是统计推断的基础
- **标签**：概率
- **章节**：ch08

### 卡片：两类错误各是什么？
- **背面**：第一类：H₀ 真却拒绝，概率 α；第二类：H₀ 假却不拒绝，概率 β
- **标签**：概率
- **章节**：ch08
