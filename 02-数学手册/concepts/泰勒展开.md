# 泰勒展开与局部近似

- **难度**：进阶 | **涉及章节**：第 5 章

## 一句话定义

用多项式在一点附近逼近一个光滑函数，阶数越高越贴合，误差由余项控制。

## 为什么重要

它是所有数值计算的基础。计算器算 `sin 0.3`、`e^2`，底层用的就是多项式逼近。它也是判断极值、估计误差、做线性化的统一工具。

## 图示

```mermaid
flowchart LR
    A[函数 f] --> B[零阶 常数]
    B --> C[一阶 切线]
    C --> D[二阶 抛物线]
    D --> E[高阶 更贴合]
    E --> F[余项控制误差]
```

看图说明：每加一阶，逼近曲线多一个弯，局部贴合度提高。误差由余项给出，不是靠眼看。

## 详解

展开式为 `f(x)=Σ f⁽ᵏ⁾(a)(x−a)ᵏ/k! + Rₙ`。余项的拉格朗日形式给出误差上界，计算时用它判断取几阶够用。

**一阶展开就是线性化**：`f(x)≈f(a)+f'(a)(x−a)`。单摆在小角度下的近似 `sin θ≈θ` 就是取一阶。

**二阶展开用于判极值**：`f''` 的符号决定凹凸，这也是多元判别式的来源。

**类比**：用不同阶的曲线去套一个复杂形状。直尺套不上的地方，改用弯曲的尺。失效边界：只在展开点附近有效，离远了误差会失控。

**实例**：`sin x ≈ x − x³/6`，在 x=0.5 时，误差约为 `x⁵/120 ≈ 0.00026`，已经很小。

## 常见误解

- **别以为阶数越高一定越好**——超出收敛半径后，高阶项会让结果发散。
- **别以为展开点可以随便选**——离数据点太远，误差会变大。
- **别以为余项可以省略不看**——不知道误差多大，就不知道结果有几位可信。
