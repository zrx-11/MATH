# 速查表

## 初等公式

| 场景 | 公式 |
|---|---|
| 复利终值 | `S=P(1+i)ⁿ` |
| 复利现值 | `P=S/(1+i)ⁿ` |
| 年金终值 | `S=R[(1+i)ⁿ−1]/i` |
| 年金现值 | `P=R[1−(1+i)⁻ⁿ]/i` |
| 二次方程求根 | `x=(−b±√(b²−4ac))/(2a)` |
| 立方和 | `a³+b³=(a+b)(a²−ab+b²)` |

## 几何与三角

| 场景 | 公式 |
|---|---|
| 正弦定理 | `a/sinA=b/sinB=c/sinC=2R` |
| 余弦定理 | `c²=a²+b²−2ab cosC` |
| 三角形面积 | `S=(1/2)ab sinC` 或海伦公式 |
| 球面余弦定理 | `cos c=cos a cos b+sin a sin b cos C` |
| 圆的曲率 | `κ=1/R` |
| 高斯曲率 | `K=κ₁κ₂` |

| 场景 | 公式 |
