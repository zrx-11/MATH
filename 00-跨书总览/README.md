# 跨书总览：数学学习路线

这三本书不是同一类东西，把它们并列摆在一起，反而能看出数学的三个层次：

- 《什么是数学》讲**为什么**：一个结论怎么被想出来，论证链怎么搭。
- 《数学手册》讲**怎么算**：遇到问题查哪条公式，套用要注意什么。
- 《普林斯顿数学指南》讲**在哪里**：这个分支在整个数学里占什么位置。

## 推荐学习顺序

| 顺序 | 书 | 为什么在这个位置 | 能力里程碑 |
|---|---|---|---|
| 1 | 《什么是数学》 | 建立推理习惯。零基础最缺的不是公式，是"为什么这一步成立"的判断力 | 能独立复述一个完整证明（如 √2 无理、素数无穷），并指出它依赖哪条前提 |
| 2 | 《数学手册》 | 有了推理习惯再学算，公式才不会变成死记。它按"查什么"组织，适合边用边学 | 拿到一个计算任务，30 秒内定位到章、节、公式，并说出适用条件 |
| 3 | 《普林斯顿数学指南》 | 前两本给的是"点"和"线"，这一本给"面"。放在最后读，才知道自己学的每一块在地图上什么位置 | 看到一个陌生分支名，能说出它研究什么、借用谁的工具、服务谁 |

## 各书定位（一句话）

- 《什么是数学》：用初等材料讲透"数学是怎么长出来的"，覆盖数系、几何、拓扑、极限、微积分。不适合想快速查公式的人。
- 《数学手册》：工具书，1500 多页公式。不适合从头读，适合有具体问题时查，也适合当复习清单。
- 《普林斯顿数学指南》：全景地图加概念词典。不适合当教材，适合建立视野、判断方向。

## 三本书怎么互相补

| 场景 | 用哪本 |
|---|---|
| 某个定理看不懂推导 | 《什么是数学》对应章节 |
| 要算一个积分或解一个方程 | 《数学手册》对应章节 + 速查表 |
| 想知道这个方向值不值得深入 | 《普林斯顿数学指南》分支章 |
| 想搞清楚"无穷"到底有几种 | A 第 2 章 + C 第 4 章（基数） |
| 想知道为什么尺规作不出正七边形 | A 第 3 章 + C 第 8 章（不可能性问题） |
| 想理解特征值有什么用 | B 第 4 章 + C 第 5 章（表示论与谱） |

## 学习节奏建议

**每周 6—8 小时，24 周走完。**

- 第 1—8 周：《什么是数学》每周一章。这八章难度递增，第 2、4、8 章最费时间，别赶。
- 第 9—16 周：《数学手册》每周一章。每章先看"查哪一节"对照表，再挑两三个例子动手算，不要通读。
- 第 17—24 周：《普林斯顿数学指南》每周一章。读的时候手边放着前两本的目录，看到交叉点就回去翻。
- 每四周做一次交叉复习：打开跨书概念映射表，挑三个概念，看三本书各自怎么讲。

## 不建议的做法

- 三本同时开。三本的语域差别大（推导、查表、综述），同时读会互相干扰。
- 先读 C 再读 A。C 假设你已有基本术语，零基础直接读会浮在表面。
- 把 B 当教材通读。它是工具书，通读的结果是记不住任何一条。
