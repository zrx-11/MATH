# 综合检验建议

八周一本，三本走完二十四章之后，用下面五道题检验"能不能把三本书接起来"。每道题都需要同时调动至少两本书。

## 跨书整合题

### 题 1：为什么 √2 不是有理数，而"有理数不够用"又是怎么回事

- 涉及：A 第 2 章、C 第 4 章（基数）
- 要求：先用反证法证明 √2 无理（A 的路子），再说明有理数在数轴上"稠密但有洞"，最后指出实数的基数比有理数大（C 的基数论证）。
- 评分要点：反证法的前提说清楚（假设互素）；"稠密"与"完备"分开讲；能说出可数与不可数的区别。
- 常见失分：把"稠密"当成"连续"。

### 题 2：从"极值为什么存在"到"极值怎么求"

- 涉及：A 第 7 章、C 第 4 章（紧性）、B 第 5 章（多元极值）
- 要求：证明闭区间上连续函数必有最大值（A/C 的紧性路线），再用 B 的梯度与二阶判别式求一个具体函数 `f(x,y)=x²+y²−2x−4y` 的极小点。
- 评分要点：存在性证明要提到"有界闭"两个条件；求解部分要给出驻点、判别式、结论三步。
- 常见失分：直接求导找驻点，跳过存在性；或者只算驻点不判类型。

### 题 3：尺规为什么作不出正七边形，而正十七边形可以

- 涉及：A 第 3 章（数域与尺规代数）、C 第 8 章（不可能性问题）
- 要求：说明尺规能作的数属于"由有理数经加减乘除与开平方得到"的域，正七边形需要解一个三次不可约方程，正十七边形对应的方程次数是 2 的幂。
- 评分要点：把"能作"翻译成"域扩张次数是 2 的幂"；指出七与十七的差别在 `p−1` 是否为 2 的幂。
- 常见失分：只说"七边形难画"，没给出代数理由。

### 题 4：用贝叶斯公式算一个真实场景，再指出它的假设边界

- 涉及：B 第 8 章、C 第 7 章（应用）
- 要求：设某病患病率 1%、检测灵敏度 99%、特异度 95%，算阳性者患病概率；再讨论"如果这人是高风险人群（患病率 10%）结果如何"。
- 评分要点：算对 16.7% 与 68.8% 两个数；说清先验改变如何影响后验；指出条件独立假设在真实检测里可能不成立（重复检测相关）。
- 常见失分：把灵敏度当成"阳性者患病概率"。

### 题 5：把一条物理过程写成方程，再判断它在数学地图上的位置

- 涉及：B 第 7 章（微分方程）、C 第 5 章（PDE 分支）
- 要求：写出热传导方程 `u_t=a²u_xx`，判断它属于抛物型，说明需要"初始条件 + 边界条件"，并解释为什么不能只给边界条件。
- 评分要点：分类依据（判别式为零）；定解条件的类型；指出抛物型有时间方向，缺初始条件解不唯一。
- 常见失分：把热传导当成椭圆型（因为稳态解满足拉普拉斯方程），混淆"方程"与"稳态"。

## 进阶路线

三条方向，选一条深入，另外两条了解即可。

**路线一：偏理论（适合想读数学专业的人）**
A 第 2、4、5 章打底 → C 第 2、4 章建立语言 → C 第 5 章分支地图 → 选一个分支读专著（推荐从代数或拓扑入手）。

**路线二：偏计算（适合工程与应用方向）**
B 第 1—6 章打底 → A 第 7、8 章补"为什么" → B 第 7、8 章 → C 第 7 章看应用案例 → 找一个自己的实际问题建模。

**路线三：偏视野（适合只想搞清数学是什么的人）**
A 第 1、2、8 章 → C 第 1、3、6 章 → C 第 8 章收尾。这条路线不追求计算能力，追求"看得懂数学家在做什么"。

## 自检清单

做完五道题，对照下面五条判断自己走到哪一步：

- 能说出三本书各自的定位，不混淆。
- 遇到一个结论，能分清它属于"已证""已证不可能""还开放"哪一种。
- 能写出一个公式，并说出它的适用条件。
- 能判断一个陌生分支大概在数学地图的哪一块。
- 能指出一个类比在哪里失效。
