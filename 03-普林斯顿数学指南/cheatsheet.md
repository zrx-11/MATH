# 速查表

## 基本结构与公理

| 结构 | 公理要点 |
|---|---|
| 群 | 封闭、结合、单位元、逆元 |
| 交换群 | 群 + 交换律 |
| 环 | 加法成群、乘法结合、分配律 |
| 域 | 环 + 非零元对乘法成群 |
| 向量空间 | 加法成群 + 标量乘法的分配与结合 |

## 几类几何与不变量

| 几何 | 变换群 | 不变量 |
|---|---|---|
| 欧氏 | 刚体变换 | 距离、角度 |
| 相似 | 相似变换 | 角度、长度比 |
| 射影 | 射影变换 | 交比 |
| 拓扑 | 同胚 | 连通性、亏格、欧拉示性数 |

## 关键数

| 对象 | 数值 |
|---|---|
| 球面亏格 | 0 |
| 环面亏格 | 1 |
| 欧拉示性数 | `χ=2−2g` |
| 球面高斯曲率 | `1/R²` |
| 平面、柱面高斯曲率 | 0 |
| 可数无穷基数 | `ℵ₀` |
| 实数基数 | `2^ℵ₀`（连续统假设说等于 ℵ₁，独立于 ZFC） |

## 分支速查

| 分支 | 核心问题 |
|---|---|
| 数论 | 素数分布、丢番图方程 |
| 代数几何 | 多项式解集的结构与奇点 |
| 几何 | 度量与曲率下的分类 |
| 拓扑 | 连续形变下的不变量 |
| 表示论 | 把群变成矩阵 |
| PDE | 解的存在、唯一、稳定 |
| 组合 | 离散结构的计数与必然出现 |
| 逻辑 | 形式系统的能力与边界 |
| 复杂性 | 问题需要多少资源 |
