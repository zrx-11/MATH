# 速查表

## 公式与规则

| 场景 | 内容 |
|---|---|
| 等差级数求和 | `n·a + d·n(n−1)/2` |
| 等比级数求和 | `a(qⁿ−1)/(q−1)`，q≠1 |
| 前 n 项平方和 | `n(n+1)(2n+1)/6` |
| 二项式系数递推 | `C(n,k)=C(n−1,k−1)+C(n−1,k)` |
| 最大公因数 | `gcd(a,b)=gcd(b, a mod b)` |
| 费马小定理 | p 素、p∤a 时 `a^(p−1) ≡ 1 (mod p)` |
| 欧拉公式 | 简单多面体 `V−E+F=2` |
| 欧拉示性数与亏格 | 可定向闭曲面 `χ=2−2g` |
| 交比 | `(A,B;C,D)=(AC/BC)/(AD/BD)` |
| 棣莫弗公式 | `(cosθ+i sinθ)ⁿ=cos nθ+i sin nθ` |
| 均值不等式 | `(a+b)/2 ≥ √(ab)`，等号 a=b |
| 重要极限 | `lim sin x/x = 1`（x→0，弧度制） |
| 欧拉数 | `e = lim(1+1/n)ⁿ ≈ 2.71828` |
| 基本定理 | `d/dx ∫ₐˣ f = f(x)`；`∫ₐᵇ f = F(b)−F(a)` |
| 指数方程 | `y'=ky` 的解 `y=Ce^(kt)` |

## 常用判据

| 问题 | 判据 |
|---|---|
| 正 n 边形可作？ | n = 2^k × 互不相同的费马素数之积 |
| 三次多项式不可约？ | 无有理根（有理根只可能是常数项因数除以首项因数） |
| 数列收敛？ | 单调 + 有界；或按 ε-N 定义给出 N |
| 连续函数有最值？ | 定义域闭且有界 |
| 点是极值点？ | 驻点 + 导数变号（或二阶导符号） |
| 两个曲面同胚？ | 同亏格且同定向性 |

## 三个古希腊难题的失败原因

| 问题 | 要求的数 | 卡在哪 |
|---|---|---|
| 倍立方 | ³√2 | 次数 3，不是 2 的幂 |
| 三等分 60° | 2cos20° | 次数 3，不是 2 的幂 |
| 正七边形 | cos(2π/7) | 次数 3，不是 2 的幂 |
| 化圆为方 | √π | π 是超越数，不属于代数数 |

## 四门几何守住的量

| 几何 | 变换 | 不变量 |
|---|---|---|
| 欧氏 | 刚体运动 | 长度、角度、面积 |
| 仿射 | 平移+线性变换 | 平行、中点、共线 |
| 射影 | 中心投影 | 交比、共线 |
| 拓扑 | 任意连续变形 | 连通性、洞数、定向性 |
